# Project Rules

## Idioma
- Código: inglés
- Comentarios: español
- Commits: inglés (convencional)

## Arquitectura
- Domain no importa nada de Infrastructure ni de EF Core
- Repositorios se definen como interfaces en Domain/

## Git
- feature/* para nuevas funciones
- fix/* para correcciones
- Sin push directo a main

## Estructura
- Un archivo = una clase pública
- Sin código comentado en commits
