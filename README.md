# Umbral — Monorepo

Monorepo que agrupa tres proyectos:

| Proyecto | Tecnología | Carpeta |
|---|---|---|
| API REST | C# / ASP.NET Core | `Umbral.WebAPI/` |
| Web | Next.js 16 + Tailwind v4 | `umbral-web/` |
| Mobile | React Native + Expo 54 | `umbral-mobile/` |

---

## Prerrequisitos globales

| Herramienta | Versión mínima | Verificar con |
|---|---|---|
| Git | 2.x | `git --version` |
| Node.js | 20 LTS | `node -v` |
| npm | 10+ | `npm -v` |
| .NET SDK | 8.x | `dotnet --version` |
| Docker Desktop | 24+ | `docker --version` |
| Expo CLI | latest | `npx expo --version` |
